# PaperGame vision (the original brief, kept word for word)

This is the message the project owner wrote when handing development over. It is the
north star for every phase: check new work against it. Do not edit the quoted text.

## Status checklist (updated Alpha 3.2 dev)

Built:
- [x] Arcane slower, with attack speeds that vary and speed up with tiers
- [x] Mage (arcane bolts, storm, fire + fire mega spells, 4 armors)
- [x] North Wizard: Wave (flood), Hurricane, Snowgrave (>100 mana), Noelle's Cloak
- [x] Druid: plants on the ground, ranged thorns, Bear Form, Wild Growth
- [x] Necromancer: darkness, minions, kill bonuses, 2 mega spells
- [x] Witch (potions, hexes, broom), orbs and tomes as main weapons
- [x] Monk Aura Dragon (now a fire dragon)
- [x] Special themed last rooms, mimic chest rooms, wandering merchant (reserve for next level, never behind a boss)
- [x] Survival / mini-boss arena between bosses, camera on the player
- [x] Pencil Case perma upgrades, knockoff PS2 controller setup, auto-aim kept
- [x] Visually distinct stages with their own enemies and bosses (Notebook, Ink Sewers, Paper Castle, Necrotery)
- [x] The gnome + secret kit
- [x] Sections: Necrotery graveyard (rain, lightning, breakable tombs, Gargoyles, Demonic Gargoyle mini-boss)
- [x] Heavy merged into Berserker (owner's call): Tower Shield, Boulder, Earthbreaker hammer, Earthsplitter rock line,
      Thorn Armor, Brotherhood Armor. Low-HP damage boost stays on the axes only.
- [x] Cupid (Arcane, designed by Nicolas): Harp, Heart Wand, Cupid's Bow, Wing Flap, Cupid's Flight, Cupid's Book

Not built yet:
- [ ] Paladin (melee, mana, divine, support/healing, satisfying sword projectiles)
- [ ] Heavy (now part of Berserker): big swords, lava attacks still to come
- [ ] Samurai (katanas, shadow/dragon spells, speed, getting behind enemies)
- [ ] More shields: with attacks for some melee classes, a few for other classes, magic shields for Arcane
- [ ] Precision throwable metal shield (charges up from blocks, homes on a few enemies, comes back)
- [ ] Ninja
- [ ] Outlaw: pirates (guns, cannons, parrots, bombing mega spell), cangaceiros (peixeira, real Portuguese names),
      cowboys, desperados, bushrangers, donkeys/horses
- [ ] More Precision subclasses in general (only Archer and Hunter so far; Arcane has 5, Melee 4)
- [ ] Mage potions; Druid creature summons and more animal forms; more Monk wind abilities
- [~] ★★★★ gear tier: exists (Hot Coal Lump is the first item); needs stage 4 to show up in shops
- [ ] Run length: ~5 stages (have 3), a path choice after every boss, a final level full of mini-bosses, a final boss
- [ ] More original bosses (Deltarune / Terraria flavour, no spoilers)
